# Narrator Studio

An Android app (Flutter) that reads `.txt`, `.md` and `.pdf` files aloud in
many free, on-device voices, and turns scripts into podcast episodes you can
export and publish.

* **Voices** (downloaded inside the app, then fully offline):
  * Kokoro v1.0: 54 natural voices (American, British, and English with Spanish, French, Hindi, Italian, Japanese, Portuguese flavors). Fast fp32 model by default; a compact int8 option for small phones.
  * Supertonic 3: 10 voices that generate about 4× faster.
  * Pocket TTS: voice cloning from a 10-second clip, used by the **Voice Gallery** (344 CC0 / CC-BY voices: LibriVox narrators, voice actors, VCTK speakers, donated voices) and by **Clone a voice** (your own voice, with consent).
  * **Voice mixes**: blend two Kokoro voices into a new one.
* **Styles**: audiobook, podcast, lecture, interview, story, briefing, each with its own pacing, default cast and music.
* **Scripts**: speaker tags (`HOST:`), sections (`## Part 1`), `[pause 2]`, `[sound: chime]`, `[music: outro]`. See [GUIDE.md](GUIDE.md).
* **Music**: four original themes generated by the app (no licenses), ducked under speech.
* **Read-along**: the sentence being read is highlighted; tap any sentence to jump; your place is saved.
* **Background**: keeps reading with the screen off, with notification, lock-screen and headset controls.
* **Export**: M4A (AAC) or WAV, saved to Downloads or shared.
* **Write with Claude**: copy-paste prompts per style; paste or share the reply back. No API keys.

## Install

Download `narrator-studio.apk` from the
[narrator-studio-latest release](https://github.com/pruittcolon/Vox_Amelior/releases/tag/narrator-studio-latest)
on your phone, open it and allow installs from that source. In the app, open
**Voices** and download **Kokoro** (about 375 MB, Wi-Fi recommended).

The same release has `sample-podcast.m4a`: the built-in sample rendered in CI
with the real voices, so you can hear the quality first.

## How it is built

* `lib/core/script/` parse text and scripts, clean PDFs, split sentences, prompts for Claude.
* `lib/core/render/` styles, the plan (what is said, gaps, cues), music, the renderer that mixes it all.
* `lib/core/tts/` voices and characters, voice mixes, the sherpa-onnx worker isolate.
* `lib/core/models/` voice-pack catalog (generated from the release manifest) and the resumable, checksummed downloader.
* `lib/core/audio/` player (renders ahead, follows sentences), exporter, the Android bridge.
* `android/` Kotlin: streaming AudioTrack player, foreground service with media session, AAC encoder, audio decoder, mic recorder, sharing.
* `tool/models/` CI scripts that republish the models unpacked, test every voice with Whisper, and build the Voice Gallery.
* `tool/render_demo.dart` renders the sample podcast with the real voices using the app's own pipeline.

CI (`.github/workflows/narrator-studio.yml`): analyze, unit + widget tests,
360 dp screenshots at 1× and 1.3× text, a real-voice render checked by Whisper,
then a signed APK. `.github/workflows/narrator-models.yml` maintains the
`narrator-models` release.
